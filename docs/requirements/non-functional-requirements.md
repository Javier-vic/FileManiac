
# Non Functional Requirements


### NFR-001 — Local Processing
The application shall process user files locally on the user's computer.

### NFR-002 — No File Upload
The application shall not upload user files to external servers.

### NFR-003 — Offline Operation
The core functionality shall be available without an Internet connection.

### NFR-004 — Privacy
The application shall not collect or transmit personal data or information contained in user files.

### NFR-005 — Performance
The application shall process PDF operations without blocking the user interface.

### NFR-006 — Reliability
The application shall handle invalid or corrupted PDF files without terminating unexpectedly.

### NFR-007 — Usability
The application shall provide clear feedback about the status and result of each operation.

### NFR-008 — Compatibility
The application shall run on supported versions of Windows.

### NFR-009 — Maintainability
The application shall follow a modular architecture that allows individual components to be modified or replaced with minimal impact on other components.
