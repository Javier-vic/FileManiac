# Problem

The majority of applications used to merge, split, or convert files to PDF are web-based. This can be a problem when working with confidential or sensitive information, as users may be required to upload their files to third-party servers.

# Goal

Create a desktop application that runs entirely locally and provides users with a suite of tools for managing PDF documents. The application should support operations such as merging multiple PDF files, splitting existing documents, and converting files from other formats into PDF.

All document processing should take place locally on the user's computer. The application should be available free of charge and should not collect, upload, or transmit any personal data or user files.

# Scope

The initial version of the application will provide the following PDF operations:

- Merge multiple PDF documents into a single file.
- Split PDF documents into multiple files.
- Reorder pages within a PDF document.
- Remove pages from a PDF document.
- Rotate pages.
- Convert supported file formats into PDF.
- Process all files locally without requiring an Internet connection.

The initial version will not include cloud storage, user accounts, or any functionality that requires uploading documents to external services.
